# 译派 YiPai

> 任务派下来，译员选得快 🎀

面向中小型翻译服务商 / 本地化项目负责人的**轻量化译员档案管理 + 智能派单推荐工具**（MVP）。

## ✨ 功能

| 模块 | 说明 |
|---|---|
| 🗂 译员档案 | 20 条示例档案，支持搜索筛选、新增编辑；数据保存在本机浏览器（localStorage） |
| 📄 文件导入 | 上传 `.docx / .xlsx / .pdf / .txt / .md / .csv` 译员简历，自动识别字段并归位，缺失项黄色提醒补全 |
| 🎯 智能匹配 | 严格五级优先级：语言对 → 专业领域 → 档期（空闲 > 部分占用，已满排除）→ 历史评分 → 千字单价；输出 Top3 + 推荐理由 + 风险提示，可一键复制 Markdown |
| 📅 档期日历 | 按天可视化每位译员档期；译员可切换自助模式更新自己的排期，改动自动折算总档期并即时影响匹配 |
| 🙋 派派引导 | IP 吉祥物"派派"带你 30 秒上手 |

## 🚀 使用

**在线演示**：https://53494.github.io/yipai/

**本地运行**：无需安装任何东西——双击 `index.html` 即可用。
（PDF 导入依赖 `vendor/` 目录，移动文件时请连同该目录一起。）

## 🧪 测试样例

`samples/` 内含四份译员档案样例（字段齐全 / 表格式 / 缺字段 / 纯文本），可在"新增译员"弹窗中上传体验自动识别。

## 🛠 技术说明

- 单文件 HTML + 原生 JS，零框架、零后端、零外部服务
- PDF 解析使用 [pdf.js](https://cdnjs.cloudflare.com/ajax/libs/pdf.js/3.11.174/)（本地引入）
- 匹配引擎完全可解释，不使用黑盒模型

## ⚠️ 声明

档案数据均为演示用虚构数据，存储于浏览器 localStorage，不上传任何服务器。
